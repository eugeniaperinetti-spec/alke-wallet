# Alke Wallet

Alke Wallet es una aplicación web de billetera digital desarrollada para el Módulo 2 de Fundamentos del Desarrollo Front-End.

## Funcionalidades

- Inicio de sesión con validación.
- Protección de páginas privadas.
- Visualización del saldo.
- Depósito de fondos.
- Transferencias a contactos.
- Registro de movimientos.
- Creación de contactos.
- Búsqueda y selección de contactos.
- Cierre de sesión.
- Almacenamiento de datos con localStorage.
- Diseño responsive.

## Uso de la aplicación

1. Abrir index.html.
2. Presionar Iniciar sesión.
3. Ingresar las credenciales de prueba.
4. Utilizar el menú para depositar, transferir o revisar movimientos.
